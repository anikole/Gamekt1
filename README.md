Это текстовая игра квест, отображающаяся в терминале символами ASCII. 
В этой игре есть 5 локаций, различные головоломки, сундуки с наградами (в псоледнем особая награда за прохождение игры).

---

## 🚀 Особенности проекта

* 🗺️ **Динамический мир**: Исследование локаций и взаимодействие с окружением (двери, сундуки).
* 🧩 **Головоломки (BrainBreaker)**: Интегрированная система текстовых загадок и мини-игр.
* 🎒 **RPG-система**: Управление персонажем, прокачка и инвентарь с зельями.
* 💻 **Кроссплатформенность**: Проект легко собирается и работает как на Windows, так и на Linux благодаря универсальному Makefile.

---

## 🛠️ Сборка и запуск

Проект собирается с помощью утилиты `Make` и компилятора `g++` (с поддержкой стандарта C++17).

### 1. Сборка проекта
Откройте терминал в корневой папке проекта и выполните команду:

* **В Windows (через MinGW):**
  ```bash
  mingw32-make
  ```
* **В Linux :**
  ```bash
  make
  ```

### 2. Запуск игры
* **В Windows:** `my_program.exe`
* **В Linux:** `./my_program`

### 3. Очистка временных файлов
Если нужно удалить объектные файлы (`.o`, `.d`) и исполняемый файл:
```bash
make clean        # Для Linux
mingw32-make clean # Для Windows
```

## 🕹️ Как играть (Управление)

Игра управляется через консоль с помощью ввода текстовых команд или цифр. 
* Выбор действий в меню: введите `INV` для открытия инвентаря и нажмите **Enter**.
* Перемещение: команды направления : UP(или U), DOWN(или D), LEFT(или L), RIGHT(или R).
* Использование предметов: откройте инвентарь и выберите номер зелья для использования.

## 🏗️ Архитектура и Классы

Проект построен на объектно-ориентированном подходе (ООП):

* **`game`** — Главный цикл игры, обработка ввода и игровая логика.
* **`Location`** — Модель игровой комнаты, хранящая связи с объектами и другими локациями.
* **`Character`** и **`Inventory`** — Логика персонажа, его характеристик и содержимого сумки.
* **`Potions`**, **`Chests`**, **`Door`** — Интерактивные объекты игрового мира.
* **`BrainBreaker`** — Модуль загадок и логических испытаний.

* Утилита `Make` (или `mingw32-make` для Windows).
