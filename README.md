Это текстовая игра квест, отображающаяся в терминале символами ASCII. 
В этой игре есть 5 локаций, различные головоломки, сундуки с наградами (в псоледнем особая награда за прохождение игры).
Для того, чтобы собрать файлы в единый exe файл в терминале нужно прописать команду : g++ game.cpp Character.cpp Location.cpp Chests.cpp Door.cpp Potions.cpp Inventory.cpp BrainBreaker.cpp -o game.exe
Для того, чтобы запустить этот exe файл нужно пропиать слудщую команду : ./game.exe
